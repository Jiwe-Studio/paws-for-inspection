Customs Officer Field Manual

Quick Discrepancy Checklist

DENY ENTRY IF ANY OF THE FOLLOWING OCCUR:

🔴 Animal is Disguised: Scrubbing reveals a different species (e.g. donkey painted as zebra, capybara disguised as retriever, smuggled lizards under coat).

🔴 Expired Permit: Expiry date is before today's customs date (OCT 14, 2026).

🔴 Weight Discrepancy: Scale reading significantly exceeds permitted limit on permit.

🔴 Name Mismatch: Passenger tag does not match the permit's declared owner.

🔴 Missing Official Seal: Permit lacks authentic CITES Hologram.

🟢 APPROVE: Clean animal, matching details, valid dates, matching weight, authentic seal.
